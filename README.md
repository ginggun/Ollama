# Ollama RAG Project

    A simple Retrieval-Augmented Generation (RAG) implementation using Python and Ollama.

    ## Overview

    This project was created as a hands-on learning exercise to understand how RAG systems retrieve relevant information from a dataset and use a local language model to generate answers.

    ## Features

    - Local LLM inference using Ollama
    - Text embeddings for semantic search
    - Cosine similarity for retrieving relevant information
    - Question answering using retrieved context

    ## Technologies

    - Python
    - Ollama
    - Hugging Face GGUF models

    ## Installation

    1. Install Ollama.
    2. Download the embedding and language models described in the tutorial.
    3. Install the Python dependency:

       `pip install ollama`

    4. Run the example:

       `python demo.py`

    ## Reference

    Based on the Hugging Face community tutorial: [Code a Simple RAG from Scratch](https://huggingface.co/blog/ngxson/make-your-own-rag).
